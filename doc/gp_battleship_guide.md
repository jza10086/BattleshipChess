# 海战棋

GodotParty API 4 小游戏，使用 GodotPartyDefault 的 standard 协议。正式入口为 `party_round.tscn`，从派对大厅的「小游戏轮换」选择海战棋开始。

## 人数与胜负

- **1 人**：单机测试，同一个玩家交替操作蓝、红两队；布阵时可切换队伍，对战时先后选好两队目标，再同轮发射。没有机器人，按两队累计命中计分，测试胜利加 100 分，玩家排名第一。
- **2–8 人**：按本轮种子随机均分两队，奇数人数相差一人；蓝、红两队各共用一片 10×10 海域和一支舰队。
- 舰船长度为 5、4、4、3、2，可相邻，不可重叠或超出海域。击沉对方全部五艘舰船获胜。
- 福特号航母占 5 格，大和号战列舰和企业号航母各占 4 格，贝尔法斯特号巡洋舰占 3 格，基德号驱逐舰占 2 格。命中时在落点播放低多边形爆炸，五艘军舰各自在全部舰格命中后切换为对应残骸。最后一击播完再显示结算。
- 每次有效命中给发射者加 1 分。胜队每名在线玩家加 100 分，按个人总分降序排名，同分并列；退出成员记为 withdrawn，不排名。双方同回合全部被击沉判平局，双方均不加胜利分，仍按命中分排名。

## 布阵与共同回合

1. 全员确认规则、完成准备倒计时后，进入 60 秒秘密布阵阶段。每队五艘舰船随机分给队内玩家，数量相差最多一艘：两人 3+2、三人 2+2+1、四人 2+1+1+1；舰船种类和多拿舰船的玩家都随机决定。
2. 每人只可操作自己的舰船：下拉选择舰船、横纵方向，再点击己方格子作为舰首位置；「随机摆放我的舰船」也不会移动队友的船。无效摆放不改变原舰队。同队所有人可见己方舰队及负责人。
3. 每人点击「我的布阵完成」确认并锁定自己的舰船，全部在线玩家确认后立即开战；布阵超时锁定现有合法布局。布阵时断线，其舰船逐艘交给当前持船最少的在线队友，同数量时随机选择；接手者重新确认，原有布局保留。单人测试仍分别操作并确认两队全部舰船。
4. 双方同时选点，每名在线玩家每回合一发炮弹。同队目标不能重复，由房主收到合法选点请求的先后决定归属；发射前可改选未被队友占用且尚未轰炸的地块，改选成功释放旧目标，失败则保留原目标。同队能看到选点者姓名，敌队和观众看不到待发目标。
5. 双方全部在线队员选好后立即齐射；超时只发射已选目标的炮弹。房主先结算双方整批炮弹，再判断击沉与胜负，因此允许同时全灭的平局。
6. 在线人数较多的队伍每轮随机选出人数差额的玩家装填哑弹，通常为一人。断线造成差额扩大时同步平衡有效炮弹配额。哑弹不命中、不得分、目标格仍可再次选择；超时未选目标的玩家不发射。
7. 单人测试在选好一方目标后自动切到另一方，也可点击切换按钮；两方都选好时一起发射。两方命中都计入测试玩家分数。

大厅规则「每轮选点时间（秒）」默认 20 秒，可设 5–90 秒，对应配置字段 `target_seconds`。Esc 使用派对菜单，打开菜单不暂停联机计时。详细规则可通过右上角按钮展开。

## 联机边界

房主持有完整状态，身份取自 PartyNet 发送者；玩家只能提交本队当前阶段和当前回合的合法操作。公共种子用于分队，秘密舰位和哑弹抽签使用房主私有随机源。

客户端只接收己方舰船与已击沉敌舰；观战者只接收公开信息。结束后才揭示两队全部舰位。房主即使观战仍负责权威计算。断线成员的选点立即释放，双方剩余队员全部选齐即可轰炸；一队全员退出时另一队获胜。房主离开仍由框架结束会话，不提供重连或主机迁移。

准备页和结算页复用协议公开资源；只有房主提交一次最终结果，轮换大游戏负责正式记分和进入下一局。新局创建全新的规则状态，不保留上局舰位、选点或命中。

## 文件与资源

- `battleship_rules.gd`：主机共同回合规则、视图过滤、个人分数排名。
- `party_round.gd`：派对生命周期、消息认证、计时、准备与结算。
- `battle_view.gd`：透视投影的全幅 3D 海域、舰船、贴边 HUD 与鼠标操作。
- `ship_display.tscn` / `ship_display.gd`：可编辑舰船展示模板，保存五组完好/残骸资源、模型挂点、负责人名字牌和独立水线材质；按已过滤视图中的舰型、舰长、朝向、沉没状态实例化。
- `i18n/zh_Hans.po`：准备说明、HUD、详细规则和结算展示共用的中文模板。独立打开 `battle_view.tscn` 可预览固定场景与规则面板，使用同一 Translation，不构造派对或写入成绩；完整单人测试仍从大厅进入。
- `settings.gd` / `adapter.gd`：房间规则和 standard 适配。
- `assets/`：五艘军舰的完好及损毁模型、Kenney 闪光贴图、Noto CJK 字体子集及海面资源，见 `doc/gp_battleship_assets_sources.md`。
- `prototype/`：原独立双人原型存档，由 `.gdignore` 隔离，不作为正式派对运行依赖。
- 收到最终视图后先校验协议结果，再播放末轮弹着并打开结算；停止会断开本包监听、停止页面与本地弹着，等待中的延迟结算不会在退出后重新打开。

定向规则及真实大厅联机检查位于主工程 `tmp/test/battleship/`。自动检查不代替跨机器联机、1920×1080 视觉与操作手感的人工验收。

1人依次操作两队测试，2–8人随机均分两队。每人抢选一个目标，双方同回合齐射；多人数队随机产生哑弹，命中+1分。击沉敌方全舰获胜，同时全灭为平局；胜队每人+100分，按总分排名。
