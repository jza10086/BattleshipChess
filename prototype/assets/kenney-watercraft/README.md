## Included files

- buoy.glb — unchanged original model (208 position vertices; x/z ±0.4641, y -0.3 to 1.5441).
- ship-ocean-liner.glb — playable five-cell ocean liner.
- ship-cargo-a.glb — playable four-cell cargo ship.
- boat-tug-a.glb — playable three-cell orange tugboat.
- boat-tug-b.glb — playable three-cell green working boat.
- boat-speed-a.glb — playable two-cell speedboat.
- Textures/colormap.png — unchanged original shared palette texture required by the GLBs.

Coordinates are glTF Y-up; buoy origins are near the waterline. Preserve the relative Textures/colormap.png path when copying these GLBs. Models contain mesh/material data only, no scripts. The principal playable fleet uses these original low-poly models, scaled/oriented at runtime to fit the board. Source models and texture are unmodified.
