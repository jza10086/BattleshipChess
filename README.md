# 海战棋

GodotParty API 4 小游戏，使用 GodotPartyDefault 的 standard 协议。正式入口为 `party_round.tscn`，从派对大厅的「小游戏轮换」选择海战棋开始。

## 人数与胜负

- **1 人**：单机测试，同一个玩家交替操作蓝、红两队；布阵时可切换队伍，对战时自动切换到当前行动队。没有机器人，完成测试后玩家排名第一。
- **2–8 人**：按本轮种子随机均分两队，奇数人数相差一人；蓝、红两队各共用一片 10×10 海域和一支舰队。
- 舰船长度为 5、4、3、3、2，可相邻，不可重叠或超出海域。击沉对方全部五艘舰船获胜。
- 胜队在线成员并列第一，负队在线成员并列第二；退出成员记为 withdrawn，不排名。

## 布阵与投票

1. 全员确认规则、完成准备倒计时后，进入 60 秒秘密布阵阶段。每队名单中第一位在线成员是队长；队长退出时顺延。
2. 队长可随机布阵，或选择舰船、横纵方向，再点击己方格子作为舰首位置。无效摆放不改变原舰队。同队所有人可见己方舰队。
3. 两队确认出航后立即开战；布阵超时锁定现有合法布局。首攻队由本轮种子随机确定。
4. 行动队每人点击敌方未轰炸地块投一票，收齐前可以改投。每人始终只有一票，同队能看到目标票数和抽中概率。
5. 全部在线队员投票后立即抽签；投票超时按已经收到的票抽签。目标概率等于该格票数除以总票数，例如 3:1 对应 75%:25%，并非必选最高票。
6. 房主抽签并判定命中，命中后也切换队伍。无人投票时跳过本轮，不自动替玩家选目标。

大厅规则「每轮投票时间（秒）」默认 20 秒，可设 5–90 秒。Esc 使用派对菜单，打开菜单不暂停联机计时。详细规则可通过右上角按钮展开。

## 联机边界

房主持有完整状态，身份取自 PartyNet 发送者；玩家只能提交本队当前阶段和当前回合的合法操作。公共种子只用于分队与首攻，秘密舰位和抽签使用房主私有随机源。

客户端只接收己方舰船与已击沉敌舰；观战者只接收公开信息。结束后才揭示两队全部舰位。房主即使观战仍负责权威计算。断线成员的票立即移除，当前剩余队员投齐即可轰炸；一队全员退出时另一队获胜。房主离开仍由框架结束会话，不提供重连或主机迁移。

准备页和结算页复用协议公开资源；只有房主提交一次最终结果，轮换大游戏负责正式记分和进入下一局。新局创建全新的规则状态，不保留上局舰位、选票或命中。

## 文件与资源

- `battleship_rules.gd`：主机规则、视图过滤、队伍排名。
- `party_round.gd`：派对生命周期、消息认证、计时、准备与结算。
- `battle_view.gd`：透视投影的全幅 3D 海域、舰船、贴边 HUD 与鼠标操作。
- `settings.gd` / `adapter.gd`：房间规则和 standard 适配。
- `assets/`：正式使用的 Kenney 舰船、Noto CJK 字体子集及原型海面资源，许可证随资源保留，见 `assets/SOURCES.md`。
- `prototype/`：原独立双人原型存档，由 `.gdignore` 隔离，不作为正式派对运行依赖。

定向规则及真实大厅联机检查位于主工程 `tmp/test/battleship/`。自动检查不代替跨机器联机、1920×1080 视觉与操作手感的人工验收。
