# 海战棋 · 静海交锋

一个独立的 **Godot 4.x 双人联机海战棋**。真正的 3D low-poly 小船、全幅海面、
正交相机与柔和阴影；船只是 Kenney 的 CC0 glTF 模型。对局中没有常驻标题、
按钮栏、操作提示、状态文字或调试面板。

## 运行

用 **Godot 4.7.2** 打开 `project.godot`，按 **F5**。也可：

```sh
godot --path .
```

使用 Compatibility 渲染器和 2× MSAA，主要面向电脑键鼠。窗口可缩放，
**F11** 切换全屏；宽屏为左右海域，窄屏自动改为上下排列，相机按真实 3D 边界取景。
项目不包含引擎二进制或导出包，较旧 Godot 4.x 小版本不作兼容保证。

## 两人连接

1. 房主选择 **1024–65535 的 UDP 端口**（默认 **17777**），点击「创建」。
2. 另一人输入房主可达的 IP 地址及同一端口，点击「加入」。
3. 同一台电脑打开两个实例时使用 `127.0.0.1`。不同电脑使用房主的局域网 IP，
   不要使用 `127.0.0.1`；Windows 可运行 `ipconfig`，Linux 可运行 `ip addr`。
4. 每间海域最多两人；满员或对战中加入的第三人被拒绝，不获得舰队数据。

使用 Godot 原生 **ENet / UDP**，无账号、第三方服务器或 AI 对手。
公网直连需要房主 UDP 端口可达，可能涉及防火墙与路由器端口映射。
本项目**不提供中继、自动 NAT 穿透或匹配服务**，不保证任意公网设备可直接连接。
只与信任的人共享地址；没有身份认证或加密传输。连接中可点「取消」或按 Esc。

官方说明：[Godot High-level multiplayer](https://docs.godotengine.org/en/stable/tutorials/networking/high_level_multiplayer.html)。

## 玩法

- 双方各有一片 **10 × 10** 海域。舰队长度 **5 / 4 / 3 / 3 / 2**，共 **17 格**。
- 五艘船以远洋轮、货轮、橙色拖轮、绿色工作艇与快艇呈现；仅美术改变，经典规则不变。
- 开局已有一组可调整的有效布阵，所有船直接显示在自己的水面上。
- **直接拖动船只**到新位置，或单击船只选择，再单击空格放置。**R / 右键**旋转。
  **1–5** 也可选船，Esc 取消选中；金色格可放，珊瑚色格无效。
- 船只不能重叠或越界，**允许相邻接触，不强制留水道**。无效放置不会破坏原布局。
- 唯一的部署确认是「出航」，确认后消失；双方确认后开始。已就绪的舰队不能再移动。
- 轮到你时，目标海域网格轻亮、可射击格显示环形准星；否则不显示可操作准星。
- 点击目标海域的未射击格。**命中也不连击，每次有效射击都换手**。
- 攻击过的网格直接着色：**蓝色为未命中，红色为命中**，辅以平面圆环 / 叉号。
  标记贴在网格上，己方船体遮挡时仍可辨认；没有悬浮箭头。敌舰只有击沉后才出现，
  并缓慢下沉。不能重复射击。
- 击中全部 **17 格 / 5 艘舰船** 获胜；结束才公开双方舰队。
- 「再来一局」需双方同意，清空旧局并重新布阵；第一局房主先手，以后先手轮换。
- **Esc** 打开精简菜单，可继续、重新布阵（仅未就绪时）、切换声音或离开。
  菜单不暂停另一人的联机对局，没有常驻菜单按钮。

对方断线会结束当前局：房主保留房间并清空上一局，等待新玩家；房主断线时客机返回入口。
断线检测可能需要数秒。无中途重连继承、旁观、单机 AI 或同屏轮流模式。

## 隐藏信息与校验

房主是裁判，只接受玩家的「就绪布局 / 射击格子 / 再战请求」，验证布局、回合、
重复射击与胜负。客户端不能自行宣称命中、改变回合或冒充另一人。

每人只收到 **自己的舰队 + 公共射击记录 + 已击沉敌舰**；未结束前不向客机发送
其他敌舰位置。3D 场景也不创建隐藏敌舰模型，不是收到完整布局后仅遮住模型。
结束后才公开完整敌舰，再战清除全部旧局信息。UI 不直接修改裁判状态。

**房主进程为裁判，必然知道双方布局**，不是防恶意房主的密码学公平协议。
RPC 有类型、身份、状态、坐标、舰队合法性与频率限制，但本项目不是面向不可信公网的
专业竞技服务，建议在受信任的局域网 / 私人网络中游玩。

## 结构与验证

- `scripts/rules.gd`：无 UI 的权威规则与私有快照，3D 改版未改动。
- `scripts/network.gd`：ENet 房间、准入、定向快照、请求验证与断线处理，未改动。
- `scripts/main.gd`：真实 Node3D 场景、相机与网格、射线拾取、输入、极简界面和音效。
- `scripts/ship_visual.gd`：Kenney GLB 实例、物理碰撞、浮动与沉船动画。
- `assets/shaders/ocean.gdshader`：真实平面网格上的轻微波动与水色，不是伪 3D 投影。
- `tests/`、[`docs/QA.md`](docs/QA.md)：规则、真实多进程网络及原生窗口输入验证。

```sh
GODOT_BIN=/path/to/godot ./tests/run_tests.sh
```

测试需要 Python 3。测试驱动仅在 `tests/`，正常游戏不会运行；截图来自真实游戏窗口
和独立 ENet 客机，不是设计稿或模拟快照，测试日志和截图不放入源码仓库。
