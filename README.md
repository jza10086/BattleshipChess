# 海战棋 · 静海交锋

一个独立的 **Godot 4.x 双人联机海战棋** 项目。整幅海面、两片真正用于操作的海域，
没有常驻侧栏、调试信息或控制台面板。舰船、水纹、瞄准与命中特效均为原创程序化美术。

## 运行

用 **Godot 4.7.2** 打开 `project.godot`，按 **F5** 运行主场景。
也可使用命令行：

```sh
godot --path .
```

使用 Compatibility 渲染器，主要面向电脑键鼠。窗口可自由缩放，**F11** 切换全屏；
宽屏为左右海域，正方形 / 竖向窗口自动改为上下排列，海面始终铺满窗口。
项目不包含 Godot 引擎二进制或导出包；尚未验证的较旧 Godot 4.x 小版本不作兼容保证。

## 两人连接

1. 房主选择一个 **1024–65535 的 UDP 端口**（默认 **17777**），点击「创建海域」。
2. 另一人输入房主可达的 IP 地址及同一端口，点击「加入海域」。
3. 同一台电脑打开两个实例测试时使用 `127.0.0.1`。不同电脑请使用房主的局域网 IP，
   不要使用 `127.0.0.1`；Windows 可运行 `ipconfig`，Linux 可运行 `ip addr` 查看地址。
4. 每间海域最多两人；满员 / 对战中加入的第三人会被拒绝，不获得舰队数据。

采用 Godot 原生 **ENet / UDP**，无账号、无第三方服务器、无 AI 对手。
跨公网直连需要网络允许访问房主 UDP 端口；可能涉及防火墙和路由器端口映射。
本项目**不提供中继、自动 NAT 穿透或匹配服务**，不保证任意两台公网设备能直接连接。
只与信任的人共享地址；没有身份认证或加密传输。连接过程中可点「取消连接」或按 Esc。

官方网络说明：
[Godot High-level multiplayer](https://docs.godotengine.org/en/stable/tutorials/networking/high_level_multiplayer.html)。

## 玩法与操作

- 双方各有一片 **10 × 10** 海域，列 A–J、行 1–10。
- 舰队为 **航母 5、战列舰 4、巡洋舰 3、潜艇 3、驱逐舰 2**，共 **17 格**。
- 舰船只能水平或垂直放置，不能重叠、不能越界；**允许相邻接触，不强制留水道**。
- 在「我的海域」单击布置选中的舰船；移动鼠标预览可用位置，青色可放，珊瑚色不可放。
- **R / 鼠标右键**旋转；**1–5 / 下方舰名**选择舰船；再次单击已放置的舰船可拾取移动。
- 「随机布阵」只帮助摆放自己的舰船，不替玩家开火。未就绪前可重复调整。
- 双方点击「舰队就绪」后开始；就绪后本局舰队不能再移动。
- 轮到你时，单击「目标海域」任意未打过的格子。**命中也不连击，每次有效射击都换手**。
- 空心水纹表示未命中，珊瑚色叉表示命中；击沉后才显示整艘敌舰。已打过的格子不可重复射击。
- 击中对方全部 **17 格 / 5 艘舰船** 获胜；结束时公开双方舰队。
- 「再战一局」需双方同意，再重新布阵；每局先手轮换。第一局房主先手。
- **Esc / 菜单**可继续、关闭声音或离开；菜单不暂停另一人的联机对局。

对方断线会结束当前局：房主保留房间并清空上一局，等待新玩家；房主断线时客机返回入口。
断线检测可能需要数秒。没有中途重连继承、旁观、单机 AI 或同屏轮流模式。

## 隐藏信息与规则校验

房主是裁判，只接受玩家的「就绪布局 / 射击格子 / 再战请求」，由房主验证布局、回合、
重复射击与胜负。客户端不能自行宣称命中、改变回合或冒充另一人。

每个玩家只收到 **自己的舰队 + 公共射击记录 + 已击沉敌舰**；未结束前，不向客机发送
敌方尚未命中的舰位。没有把完整双方布局广播后仅在 UI 中隐藏的实现。
结束后才公开敌方舰队，再战会清除全部旧局信息。数据从规则模型复制，UI 不直接改裁判状态。

**房主进程为裁判，必然知道两方布局**；这不是防恶意房主的密码学公平协议。
RPC 有类型、状态、身份、坐标、舰队合法性及频率限制，但该轻量游戏不是面向不可信公网的
专业竞技服务。建议在受信任的局域网 / 私人网络中游玩。

## 结构与验证

- `scripts/rules.gd`：无 UI 的权威规则与私有快照。
- `scripts/network.gd`：ENet 房间、准入、请求校验、定向快照和断线处理。
- `scripts/main.gd`：全幅海面、舰船绘制、响应式布局、输入和原创音效。
- `tests/`：确定性规则、真实多进程网络、原生窗口输入与截图验证。
- `docs/QA.md`：运行方法、覆盖范围与已验证结果。

```sh
GODOT_BIN=/path/to/godot ./tests/run_tests.sh
```

测试需要 Python 3；自动输入只存在于 `tests/`，正常游戏不会运行这些脚本。
测试截图为真实游戏窗口和独立 ENet 客机，不是设计稿或模拟快照。没有将测试日志或截图打包进源码。
